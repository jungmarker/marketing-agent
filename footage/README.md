# footage/

One folder per shoot day, named like the brief: `footage/2026-11-13/`.

Record one clip per beat and name it by beat id from the brief:

    b01.mp4          you saying beat 1
    b01_take2.mp4    another take (the editor agent picks; otherwise newest wins)
    b05_broll.mp4    cutaway for beat 5

Video files are ignored by git on purpose. They stay on your machine.

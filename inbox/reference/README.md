# inbox/reference/

Drop reels you want broken down here: a screen recording of a reel you saved,
or a video file someone sent you. The daily run has the watcher agent write a
`breakdown.md` next to each one (hook, shot table, pace, text placement, ask)
and uses it when picking the next reel.

This is how Instagram reels get "watched". Nothing in this system logs into
Instagram or downloads other people's videos; you bring the file.

Video files here are ignored by git.
